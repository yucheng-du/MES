# 功能与验证范围

[English](FEATURES.md) · [项目说明](../README.md#简体中文)

MES 保留生产主流程，并为以下管理业务提供具体办理操作。页面和菜单本身不代表流程完成；对应测试会检查状态变化和数据库中的业务结果。

| 业务范围       | 可执行操作                                                                                                         | 自动化证据                                               |
| -------------- | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| 产品与工艺     | 属性和图纸、多套共享/产品工艺、工序类型和指导文件、工单快照、归档恢复                                              | `production-parity.test.ts`、`production-parity.spec.ts` |
| 销售与工单     | 订单编辑、明细变更/复制、交付完成/关闭、有引用保护的删除、任务分派与资质有效期                                     | 生产增补测试及已有业务/浏览器测试                        |
| 车间作业       | 工位设置、上下岗、人员/工位/设备指定、收料/开工/分批完工、无料时段、主管纠正                                       | 生产增补测试及已有业务/浏览器测试                        |
| 质量与计薪     | 人工/批量/自动审核、报废分类与责任、自责报废条件自动审核、发现奖励和工资冲销、计时工资、正负人工调整               | 生产、管理和人员报表数据库测试                           |
| 采购经营       | 多物料明细、报价、合同、分次付款申请/审核/支付、入出库、报销限额与确认                                             | `management-parity.test.ts`、`management-parity.spec.ts` |
| 设备维护       | 七种状态、唯一采集绑定、区间/日统计、状态历史、维护点检模板与逐项执行、维修、模具和刀具流转                        | 设备集成与管理测试                                       |
| 工作与安全     | 任务进度、计时工作申请/审批/完工/确认、投诉和改善明细、清单执行、学习记录及考试评分                                | 管理数据库/浏览器测试                                    |
| 安灯           | 工位联系人及升级延迟、响应处理、本地报警时间线、可选去重 HTTPS 通知                                                | 管理数据库测试，使用模拟发送器                           |
| 人员权限       | 部门/岗位/联系档案、受限人员附件、逐人允许/禁止权限、自助改密、账号归档、会话撤销、可选短信登录                    | `administration.test.ts`、`administration.spec.ts`       |
| 库存与统计     | 订单独立成品库存、物料辅料、缺货及库龄预警、按审批日期的生产/报废日报、工序/订单/明细/工资汇总、CSV 导出、现场看板 | 人员报表测试及已有库存测试                               |
| 文件与 Android | 登录鉴权的图片/文本/PDF 预览、翻页缩放、同源 PDF 资源、文件/相机上传及保存、扫码/补光、更新确认、可选厂商打印      | 设备浏览器测试和 Android 单元/构建/lint                  |
| 语言与介绍页   | 中英文同页切换、表单保持及语言记忆、响应式界面、独立 GitHub Pages 介绍页                                           | `i18n.spec.ts`、`project-site.spec.ts`、业务浏览器测试   |

测试位于 `apps/api/test/` 和 `tests/`。使用方法见[测试说明](TESTING.zh-CN.md)，部署时应查看对应提交的 CI 结果。

## 有意调整的行为

- 有归档或财务影响的记录保留历史，必要时以冲销和受约束的关闭替代直接删除；过期修订号不会覆盖他人修改。
- 审核、库存和工资使用事务及幂等处理。主管代录不会让主管本人获得工人的发现奖励。
- 生产与报废汇总按审核日期统计；无采集证据的设备时段保留为未知。语言切换不改变金额、录入数据和币种。
- 凭据保留在服务端，不复制公开测试用户/管理员后门、明文验证码查看、浏览器可见 MQTT 密码或任意服务器上传部署接口。管理员初始化及部署使用文档中的本地命令和 CI。

## 需要目标环境验收的部分

自动化测试使用虚构数据和模拟通知服务。真实短信/安灯外发需要自有配置；相机、打印、蓝牙和设备采集需要实物验收。Android community 包不含专有打印 SDK，可选 vendor 包需要另行获得授权的本地依赖。旧工厂数据仍需单独安排导入与对账。项目静态介绍页不等于已经托管上线的生产 MES。
